# ADR-0001: Agent 进程模型

## 状态
已接受

## 背景
VelaWear Agent 需要持续运行，感知事件、做出决策、执行动作。需要决定 Agent 的进程模型。

## 决策
采用**独立守护进程**模型，Agent 作为一个长期运行的进程，不依赖外部触发。

## 原因
1. **主动感知需求**：Agent 需要持续轮询传感器，不能等待外部触发
2. **决策连续性**：Agent 需要维护状态历史，用于趋势分析
3. **低功耗控制**：Agent 需要自主管理功耗模式切换
4. **响应时效性**：紧急情况需要毫秒级响应，不能等待调度

## 影响
- Agent 需要自己的线程，不依赖 LVGL 事件循环
- 需要管理内存使用，避免内存泄漏
- 需要实现优雅的启动和关闭流程

# ADR-0002: 事件模型

## 状态
已接受

## 背景
Agent 需要从多个传感器和系统获取数据，需要决定事件获取方式。

## 决策
采用**混合模式**：
- **轮询**：IMU、心率等高频传感器，Agent 内部定时读取
- **推送**：BLE 消息、按键、RTC 闹钟，被动接收事件

## 原因
1. **IMU 特性**：运动检测需要连续采样，轮询更简单可靠
2. **BLE 特性**：消息到达时间不确定，推送更高效
3. **按键特性**：硬件中断触发，天然适合推送
4. **功耗考虑**：轮询可以按需调整频率，推送无法控制

## 影响
- Event Manager 需要同时支持轮询和推送两种模式
- 轮询频率需要根据功耗模式动态调整
- 推送事件需要注册回调函数

# ADR-0003: 决策模型

## 状态
已接受

## 背景
Agent 需要根据状态和事件做出决策，需要决定决策的智能层次。

## 决策
采用**混合决策模型**：
- **硬编码规则**：紧急情况的即时响应（心率异常、跌倒检测）
- **可配置规则**：用户可调整的日常决策（久坐阈值、提醒时间）
- **LLM 推理**：复杂场景的智能分析（健康趋势、个性化建议）

## 原因
1. **响应时效性**：紧急情况需要毫秒级响应，LLM 调用太慢
2. **可定制性**：用户应该能调整日常提醒的阈值和时间
3. **智能性**：复杂场景需要 LLM 的推理能力
4. **功耗考虑**：本地规则比 LLM 调用更省电

## 影响
- Decision Engine 需要支持三种决策模式
- 需要定义规则优先级（紧急 > 日常 > 复杂）
- LLM 调用需要异步处理，不阻塞其他决策

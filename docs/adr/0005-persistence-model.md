# ADR-0005: 持久化模型

## 状态
已接受

## 背景
Agent 需要记住一些数据，需要决定持久化的范围和方式。

## 决策
采用**配置 + 状态快照**模式：
- **配置**：用户设置、规则阈值，持久化到文件
- **状态快照**：运动历史、健康数据，定期保存
- **事件日志**：只保留内存中最近 N 条，不持久化

## 原因
1. **存储限制**：SF32LB52 只有 16MB NOR Flash，空间有限
2. **写入寿命**：NOR Flash 写入次数有限，不能频繁写入
3. **启动速度**：状态快照可以快速恢复，事件日志不需要
4. **调试需求**：事件日志通过串口实时输出即可

## 影响
- 需要实现 cJSON 序列化/反序列化
- 需要实现定期保存机制（脏标记 + 定时 flush）
- 需要管理存储空间，防止溢出

# ADR-0006: 线程模型

## 状态
已接受

## 背景
Agent 和 LVGL 都需要运行，需要决定线程模型。

## 决策
采用**独立线程**模式：
- **LVGL 线程**：处理触摸、显示、动画，保持 UI 流畅
- **Agent 线程**：事件处理、决策、传感器轮询，不阻塞 UI
- **通信**：通过消息队列或共享内存

## 原因
1. **UI 流畅性**：LVGL 需要自己的事件循环，不能被阻塞
2. **Agent 独立性**：Agent 的决策可能耗时（如 LLM 调用），不能影响 UI
3. **功耗管理**：Agent 可以独立控制自己的轮询频率
4. **调试便利**：两个线程可以独立调试

## 影响
- 需要实现线程间通信机制
- 需要处理线程安全问题（共享状态的访问）
- 需要实现优雅的启动和关闭流程

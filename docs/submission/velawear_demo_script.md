# VelaWear 演示视频脚本（总时长不超过 5 分钟）

本脚本用于最终人工录制。录制时只展示已经现场观察到的现象；如果网络、LLM、Skill 执行或扬声器尚未通过实机验收，应保留对应段落为“待补录”，不能用串口日志代替画面或声音。

## 0:00–0:20 项目定位

镜头同时包含黄山派、腕带外设和项目仓库页面。口述：VelaWear 基于 openvela + ai_agent，面向久坐提醒、跌倒响应、健康状态和腕上交互。

## 0:20–0:55 冷启动与系统能力

拍摄设备上电、LCD 实际画面和触摸操作；屏幕旁可拍摄串口窗口。展示 Agent 启动、BLE 广播、MEMS 采样和本地降级状态。只有在画面中真实看到 LCD 内容和触摸响应后，才口述“显示和触摸已验证”。

## 0:55–1:35 BLE 伴侣通道

在 Windows 上启动独立 BLE 扫描器，展示 `VelaWear`、RSSI 和服务 UUID；随后展示 GATT 连接、特征读取、CCCD 写入和通知。串口画面同时保留 `connected err=0x00` 关联证据。

## 1:35–2:25 Wellness Skill 与主动场景

在设备上执行 `/skill` 或等效入口，展示 Skill 列表和一次实际执行；执行 `/remind`，展示 `get_current_time`、`cron_add`、`cron_list`、主动触发以及 LCD/声音/震动反馈的完整连续链路。若任一步尚未完成，本段必须标为待补录。

## 2:25–3:10 真实 AI 对话

展示团队自建服务端状态、设备网络地址和有效配置（遮盖密钥），发起一轮真实问答并拍到设备或伴侣端返回。若仍处于 independent/degrade mode，不要把本段剪辑成成功对话。

## 3:10–3:45 音频与传感器反馈

用录音设备收录扬声器实际声音，用相机拍摄 IMU 触发或模拟场景下的显示/震动反馈；同时保留串口时间线。仅有 DMA 采样峰值不能作为扬声器可听的证明。

## 3:45–4:20 代码与工程质量

展示 `app/velawear_agent`、Wellness Skill、构建命令、Apache 2.0 LICENSE、AI Coding 日志和作品介绍 PDF。可展示本次验证的 `nuttx.bin` SHA-256：`71be9a043790408bdf5121dcd0ad09492d2483cfb5d55894f2c2b03350251ad9`。

## 4:20–4:50 价值与边界

说明事件管理、规则决策、动作调度和 BLE/GATT 的组合价值；明确哪些能力已经现场验证，哪些仍需要服务端、硬件或录制补齐。结尾保留仓库地址和提交分支。

## 录制前检查

- [ ] 视频时长不超过 5 分钟，文件格式为 mp4/mov 等常见格式。
- [ ] 镜头中出现真实硬件、实际屏幕和实际声音，而不是只有终端。
- [ ] 语音功能若被宣称，唤醒词为“你好，openvela / Hello, openvela”。
- [ ] 服务端由团队维护，演示期间可稳定访问。
- [ ] 视频中的每个“已完成”均有对应的现场画面或声音证据。
